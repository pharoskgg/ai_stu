# 5×5 迷宫 Q-Learning 实验

本实验用表格型 Q-Learning，让智能体从左上角起点 `S` 到达右下角终点 `G`，同时避开障碍物 `X`。

## 运行方法

```bash
cd 05reinforcement_learning/01_q_learning_maze
python 01_q_learning_maze.py
```

可指定训练回合数或随机种子：

```bash
python 01_q_learning_maze.py --episodes 2000 --seed 42
```

依赖：`numpy`。若安装了 `matplotlib`，程序还会生成 `q_learning_result.png`，包含训练回报曲线与最终路径图。

```bash
pip install numpy matplotlib
```

## 实验设计

| 项目 | 设置 |
| --- | --- |
| 状态 | 5×5 网格位置，共 25 个状态 |
| 动作 | 上、右、下、左，共 4 个动作 |
| 起点 / 终点 | `(0, 0)` / `(4, 4)` |
| 障碍物 | `(0,2)、(1,0)、(1,2)、(1,4)、(3,0)、(3,1)、(3,3)` |
| 普通移动奖励 | `-1` |
| 撞墙或越界奖励 | `-10`，位置不变 |
| 到达终点奖励 | `+100`，回合结束 |
| 学习率 α | `0.15` |
| 折扣因子 γ | `0.95` |
| 探索策略 | ε-greedy，ε 从 `1.0` 线性下降至 `0.02` |

## 核心公式

每执行一次动作，按下式更新 Q 表：

```text
Q(s, a) ← Q(s, a) + α [r + γ max_a' Q(s', a') - Q(s, a)]
```

若 `s'` 已是终点，未来价值项取 0，因此目标值就是即时奖励 `r`。

## 预期现象

训练初期智能体频繁随机探索、撞墙，回报较低；随着 ε 衰减，滑动平均回报上升，贪心策略会找到一条从 `S` 到 `G` 的无障碍路径。每次固定随机种子运行，结果可复现。
